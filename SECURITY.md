# Security Policy

## 日本語

**セキュリティ上の問題は、[GitHubの非公開報告](https://github.com/takamasa-aiso/cdsl/security/advisories/new)から連絡してください。** 公開Issue・Pull Request・コメントには、未修正の脆弱性の詳細を投稿しないでください。

報告には、CDSLのバージョンまたはコミット、Codex CLIのバージョン、OS・Python・tmuxのバージョン、再現手順、想定される影響を含めてください。ログや画像を添える場合は、認証情報・個人情報・会話内容を除き、再現に必要な最小限の情報にしてください。

CDSLの起動連携・ローカルデータの処理・表示・画像貼り付けに関する問題を受け付けます。修正版がある場合は、[Releases](https://github.com/takamasa-aiso/cdsl/releases)で対応するCodexのバージョンと既知の制限を確認してください。

セキュリティに関係しない不具合や機能要望は、通常の[Issues](https://github.com/takamasa-aiso/cdsl/issues)を利用できます。

## English

**Please report security issues through [GitHub private vulnerability reporting](https://github.com/takamasa-aiso/cdsl/security/advisories/new).** Do not disclose details of an unpatched vulnerability in public issues, pull requests, or comments.

Include the CDSL version or commit, Codex CLI version, OS, Python and tmux versions, reproduction steps, and expected impact. Remove credentials, personal information, and conversation content from logs or screenshots, and include only what is needed to reproduce the issue.

Reports may cover CDSL's startup integration, local data handling, display, and image pasting. When a fix is released, check [Releases](https://github.com/takamasa-aiso/cdsl/releases) for Codex compatibility and known limitations.

Use the regular [Issues](https://github.com/takamasa-aiso/cdsl/issues) page for bugs and feature requests that are unrelated to security.
